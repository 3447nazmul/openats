# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

OpenATS is committed to local execution and privacy. Because OpenATS runs 100% locally on your machine with zero server upload of resume content, security risks are primarily confined to local parser handling and script execution.

If you discover a security vulnerability or security bug in OpenATS:

1. **Please report vulnerabilities directly via [GitHub Issues](https://github.com/3447nazmul/openats/issues)** with the label `security` or tag `[SECURITY]` in the title.
2. Provide a clear description of the issue, reproduction steps, and potential impact.
3. We will review and address valid security reports promptly.
